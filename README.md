### 🔭 Projeto em destaque

**WiEstoque** — Sistema de controle de estoque **em produção**, usado pela WiNET (provedor de internet)

O controle era feito em planilhas. O WiEstoque substituiu esse processo por cadastros e movimentações validados, com rastreabilidade de cada material e roteador.

- 📦 Materiais controlados por saldo e roteadores controlados um a um (patrimônio, série e MAC)
- 🔄 Saídas, devoluções e entradas com vários itens: a movimentação é gravada inteira ou não é gravada
- 📊 Histórico, relatórios por técnico e exportação em Excel e CSV
- 🔐 Login com Spring Security, sessão com cookie seguro, proteção CSRF e permissões por perfil
- 🧪 Testes unitários e de integração (JUnit + H2) rodando no CI a cada pull request
- ☁️ Deploy com Docker na AWS (EC2 + RDS), migrações de banco com Flyway

**Stack:** Java 21 · Spring Boot · Spring Security · Spring Data JPA · PostgreSQL · Flyway · React 19 · TypeScript · Tailwind CSS · Docker · AWS
